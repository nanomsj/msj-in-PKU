## 仓库说明

本仓库收录了我在北京大学学习期间的课程笔记、作业整理、复习资料等。内容按学期分类，方便查阅。

> **说明**：课件（slides）因版权原因一般不收录。

## 目录结构

```
msj-in-PKU/
├── 24Fall/
│   └── CS 101/          # 计算机科学导论
├── 25Spring/
│   ├── AI-Foundamentals/ # AI基础

```

## 使用方式

### 方式一：在线浏览

直接在 GitHub 上点击上方链接查看各个课程的资料。

### 方式二：克隆仓库

```bash
# 克隆完整仓库
git clone https://github.com/nanomsj/msj-in-PKU.git

# 进入仓库目录
cd msj-in-PKU
```
